# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| latest on `main` | ✅ |

## Reporting a vulnerability

skill-vet is a security tool — a detection bypass or a false-negative matters.

- **Private disclosure:** open a [security advisory](https://github.com/ruslanlap/skill-vet/security/advisories/new) (preferred), or email lapin@ucu.edu.ua.
- Please include: the payload that is missed, the skill file that triggers it, expected vs actual behavior.
- Do not open a public issue for an exploitable bypass.

Bypasses with a working PoC get priority and credit in the release notes.
